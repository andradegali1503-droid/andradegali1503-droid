# Visual Assets Curator

## Mission
Improve the quality, consistency, relevance, and performance of portfolio visuals.

## Procedure
1. Inventory existing assets and map them to pages/projects.
2. Identify missing, duplicated, low-resolution, poorly cropped, or inconsistent assets.
3. Prefer authentic project work and owner-provided materials.
4. Recommend image ratios, crop behavior, art direction, alt text, and responsive variants.
5. Use licensed or clearly permitted assets; record source and license when sourcing externally.
6. Do not use unrelated stock imagery to imply work the owner did not create.
7. Optimize formats, dimensions, compression, and loading behavior.

## Deliverable
`asset-audit.md` with asset inventory, replacements, sourcing notes, and optimization plan.

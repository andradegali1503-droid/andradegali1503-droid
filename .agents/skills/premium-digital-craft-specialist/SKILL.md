# Premium Digital Craft Specialist

## Mission
Elevate every interactive surface to the standard of Linear, Vercel, and Rauno Freiberg through invisible details: dynamic border spotlights, tactile sound/visual feedback, command palette (`Ctrl+K`), and flawless optical alignment.

## Procedure
1. Implement cursor-tracked radial border & surface spotlights (`--mouse-x`, `--mouse-y`) on cards so borders illuminate dynamically as the pointer approaches.
2. Provide a global Command Palette (`Ctrl+K` / `Cmd+K`) allowing recruiters and developers to jump to any view, filter projects, inspect diplomas, copy contact info, or switch themes via keyboard.
3. Add multi-layered glassmorphic depth (`backdrop-filter: blur(20px) saturate(160%)`), inner specular highlights (`inset 0 1px 0 rgba(255,255,255,0.08)`), and crisp SVG iconography.
4. Ensure every copy-to-clipboard, filter switch, and modal action triggers immediate, gratifying micro-feedback.

# Creative Coding & Generative Design

## Mission
Develop bespoke algorithmic art, real-time procedural animations, custom geometric overlays, and interactive particle systems that infuse the interface with technical artistry.

## Responsibilities
1. Write custom WebGL shaders (vertex/fragment GLSL), Canvas 2D math algorithms, and SVG generative paths.
2. Formulate noise functions (Perlin, Simplex, Fractional Brownian Motion, Voronoi) for organic mathematical motion.
3. Synchronize procedural parameters with cursor physics, scroll velocity, device orientation, and color themes.
4. Optimize rendering loops to maintain rock-solid 60fps/120fps with minimal GPU memory footprint and zero CPU thrashing.
5. Provide automatic low-power, static fallback modes for low-end mobile devices and reduced-motion user preferences.

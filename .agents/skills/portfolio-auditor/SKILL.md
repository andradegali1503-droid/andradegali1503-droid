# Portfolio Auditor

## Mission
Create an evidence-based audit of the existing portfolio before changes are made.

## Procedure
1. Inspect project files, routes, components, assets, styles, content, dependencies, and scripts.
2. Run the project when possible and inspect key pages at desktop and mobile widths.
3. Evaluate: first impression, positioning, hierarchy, navigation, project case studies, credibility, contact path, visual consistency, responsive behavior, accessibility, SEO, performance, maintainability, and broken states.
4. For each finding record evidence/location, severity (critical/high/medium/low), user impact, recommended fix, and effort.
5. Separate objective defects from subjective design opportunities.
6. Preserve strengths and flag risky changes before implementation.
7. Create a prioritized action plan; do not edit during the audit unless explicitly asked.

## Deliverable
`portfolio-audit.md` with scorecard, findings, evidence, priorities, and acceptance criteria.

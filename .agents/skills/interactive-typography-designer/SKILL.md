# Interactive Typography Designer

## Mission
Make typography the hero of the interface through kinetic character reveals, technical monospace scramble effects, fluid viewport scaling, and interactive hover distortion.

## Procedure
1. Implement a custom character/word split & cyber-scramble decode hook in React + GSAP for headlines, section numbers (`01 // PROYECTOS`), and role telemetry.
2. Pair high-impact geometric display headlines (`Space Grotesk`) with crisp editorial sans (`Plus Jakarta Sans`) and technical telemetry (`JetBrains Mono`) using tight optical tracking (`-0.04em`) and dramatic scale contrast.
3. Add interactive kinetic marquees and cursor-reactive character weight/elevation shifts on hero titles and CTA links.

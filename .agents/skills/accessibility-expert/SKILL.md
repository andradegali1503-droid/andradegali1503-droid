# Accessibility Expert

## Mission
Ensure the digital portfolio and CV can be perceived, navigated, and operated seamlessly by everyone, including users relying on screen readers, keyboard navigation, or high-contrast settings.

## Responsibilities
1. Audit and verify color contrast ratios strictly meeting or exceeding WCAG 2.1 AA (4.5:1) and AAA (7:1) for all text and interactive states.
2. Implement robust ARIA landmarks, `aria-expanded`, `aria-selected`, `aria-modal`, and logical tab order (`tabindex="0"` / `-1`).
3. Ensure 100% of the interface and modals are navigable via standard keyboard shortcuts (`Tab`, `Shift+Tab`, `Escape`, `Enter`, `Space`, arrow keys).
4. Provide descriptive alternative text for all graphics, badges, diplomas, and interactive canvas components.
5. Guarantee strict compliance with `prefers-reduced-motion: reduce` across WebGL, GSAP, and CSS transitions.

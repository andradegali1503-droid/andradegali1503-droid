# Creative Coding & WebGL Artist

## Mission
Infuse the portfolio with living, mathematically driven visual art using WebGL / Three.js / Custom GLSL Shaders & HTML5 Canvas that reacts in real time to pointer velocity, scroll progress, and active view states.

## Procedure
1. Design a bespoke interactive background canvas (e.g., an interactive topological neural/network field & cyber-grid shader) that embodies Ali's dual identity in Frontend Engineering & Network/Cloud Infrastructure.
2. Drive shader uniforms and particle vectors from normalized mouse coordinates, scroll velocity, and active theme/section state.
3. Optimize GPU performance: cap `devicePixelRatio` at `Math.min(window.devicePixelRatio, 2)`, pause rendering when the tab is hidden (`document.hidden`), and dispose buffers cleanly in React lifecycle hooks.
4. Ensure text contrast over the canvas remains razor-sharp through atmospheric vignette masking and layered glass surfaces.

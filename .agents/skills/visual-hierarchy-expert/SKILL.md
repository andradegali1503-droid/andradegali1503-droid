# Visual Hierarchy Expert

## Mission
Direct user attention with mathematical precision across the interface and document layouts, ensuring critical information is absorbed effortlessly in seconds.

## Responsibilities
1. Establish unambiguous contrast between primary, secondary, and tertiary information tiers using size, weight, tone, and spatial isolation.
2. Form natural F-pattern and Z-pattern scanning flows across both web screens and editorial resume pages.
3. Utilize negative space, subtle containment, and grouping laws (Gestalt proximity, similarity, common region).
4. Prevent cognitive overload by decluttering visual noise and suppressing non-essential decorative elements.
5. Validate hierarchy across multiple viewport densities, dark and light modes, and high-contrast environments.

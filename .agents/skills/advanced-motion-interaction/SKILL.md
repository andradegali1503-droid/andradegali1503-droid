# Advanced Motion & Interaction

## Mission
Engineer cinema-grade, fluid, and purposeful motion choreography that guides user attention, enriches storytelling, and creates emotional delight without harming readability or task performance.

## Responsibilities
1. Master GSAP, ScrollTrigger, FLIP layout animations, and physics-driven spring mechanics.
2. Choreograph staggered entrance sequences that establish clear visual reading order across views.
3. Design fluid, multi-step page and modal transitions (curtain shutters, morphing geometry, ambient zoom).
4. Implement velocity-aware interactions and smooth spatial pointer tracking.
5. Benchmark and safeguard 60fps/120fps execution, preventing main-thread layout thrashing and respecting user motion preferences.

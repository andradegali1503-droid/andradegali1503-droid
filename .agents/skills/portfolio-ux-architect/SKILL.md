# Portfolio UX Architect

## Mission
Make the portfolio understandable, effortless to navigate, and persuasive for its intended audience.

## Procedure
1. Identify primary visitors and their likely questions.
2. Define the main user journey from landing to project proof to contact/action.
3. Audit information architecture, navigation labels, page hierarchy, scanning, and mobile ergonomics.
4. Recommend the smallest clear structure that serves the portfolio's goals.
5. Improve project case-study flow: context, challenge, role, process, decisions, outcome, and visuals—using only verified facts.
6. Ensure visible and accessible contact routes and meaningful calls to action.
7. Validate flows with keyboard and narrow viewport checks.

## Deliverable
`ux-plan.md` with sitemap, user journeys, wireframe-level recommendations, and acceptance criteria.

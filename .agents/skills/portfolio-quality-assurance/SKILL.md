# Portfolio Quality Assurance

## Mission
Verify that the improved portfolio is complete, stable, accessible, responsive, and polished.

## Procedure
1. Run the project using its documented scripts.
2. Test every route, navigation link, CTA, form, project link, and interactive element.
3. Inspect desktop, tablet, and mobile breakpoints; test overflow and layout shifts.
4. Check keyboard navigation, focus visibility, reduced motion, semantic structure, and contrast.
5. Review console/network errors, broken assets, missing content, and loading states.
6. Run lint, typecheck, build, and tests where available.
7. Compare implementation against audit acceptance criteria and creative direction.
8. Report blockers honestly; do not claim tests passed unless executed.

## Deliverable
`qa-report.md` with pass/fail, evidence, severity, and unresolved issues.

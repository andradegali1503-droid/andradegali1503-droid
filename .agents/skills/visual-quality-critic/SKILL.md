# Visual Quality Critic

## Mission
Reject generic "bootstrapped dark mode" or flat static cards; enforce Awwwards Site-of-the-Day visual tension, depth, optical balance, and responsive perfection.

## Procedure
1. Audit every viewport for visual monotony: ensure contrast between monumental display typography and microscopic technical HUD annotations.
2. Verify that every card features multi-layered depth: subtle noise texture, dynamic cursor-tracked specular border (`--mouse-x`, `--mouse-y`), 3D perspective tilt, and smooth image scale transitions.
3. Check that WebGL canvas, GSAP scroll triggers, custom magnetic cursor, and SPA page transitions operate at 60fps without layout shift or clipping on both desktop (`1440px+`) and mobile (`390px`).

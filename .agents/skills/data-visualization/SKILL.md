# Data Visualization

## Mission
Translate complex technical competencies, multi-year timelines, operational data, and skill clusters into intuitive, beautiful, and informative visual graphics.

## Responsibilities
1. Design clear, accessible progress meters, radar charts, comparative matrixes, and timeline paths.
2. Select chart and graph types that communicate real data truthfully without distorting scale or misleading context.
3. Integrate live/interactive visual telemetry (e.g. latency readings, server loads, sensor status) with responsive rendering.
4. Ensure data color palettes adhere to accessible contrast guidelines and distinguish categories unmistakably.
5. Provide accessible semantic table fallbacks and text descriptions for screen readers and search bots.

# Microinteraction Design

## Mission
Elevate the interface with subtle, purposeful, and polished micro-feedback that communicates state changes, rewards exploration, and reinforces the feeling of physical tactile precision.

## Responsibilities
1. Design reactive hover, focus, active, and copy states with sub-millisecond tactile responsiveness.
2. Formulate magnetic cursor dynamics, specular border glows, button ripple responses, and subtle soundless haptics.
3. Coordinate micro-animations across command palettes, modal dialogs, lightbox triggers, and chip toggles.
4. Keep micro-timings crisp (120ms–350ms) so interactions feel instant and never block or lag user intent.
5. Respect `prefers-reduced-motion` settings unconditionally by suppressing decorative motion and keeping state changes instantaneous.

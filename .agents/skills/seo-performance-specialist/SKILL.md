# SEO & Performance Specialist

## Mission
Improve discoverability, accessibility, and speed without compromising the creative direction.

## Procedure
1. Inspect metadata, titles, descriptions, canonical URLs, headings, sitemap, robots, structured data, and social previews.
2. Check semantic HTML, accessible names, keyboard focus, contrast, alt text, and form labels.
3. Audit image sizes, formats, lazy loading, fonts, JavaScript, CSS, and third-party scripts.
4. Measure performance using available tools; report actual results and test conditions.
5. Prioritize Core Web Vitals and user-perceived loading.
6. Avoid keyword stuffing and unsupported structured claims.
7. Implement fixes and retest.

## Deliverable
`seo-performance-report.md` with baseline, fixes, measurements, and remaining issues.

# Ali Alejandro Andrade Godoy — Portafolio Profesional (`ali-ajelandrox.github.io`)

Portafolio web, Currículum Vitae interactivo/imprimible, catálogo de proyectos Front-End y galería verificada de certificaciones oficiales (**SEPE España** y **Academia Desafío Latam**) de **Ali Alejandro Andrade Godoy** (Desarrollador Web Front-End / Full Stack JavaScript & Técnico Superior Universitario en Informática).

## Estructura del Proyecto

- [`index.html`](./index.html) — Portada principal del portafolio: posicionamiento técnico, caso de estudio destacado (*Sombra de Valoria*), proyectos verificados con filtrado en vivo, matriz de competencias (Web + Cloud/Ciberseguridad + Sistemas/ERP), trayectoria profesional/académica, galería interactiva de 7 diplomas y contacto directo.
- [`src/routes/cv.html`](./src/routes/cv.html) — Currículum Vitae completo con visor modal accesible de diplomas oficiales y hoja de estilos de impresión (`@media print`) para exportar a PDF limpio.
- [`src/routes/proyects.html`](./src/routes/proyects.html) — Catálogo detallado de los 6 proyectos verificados con filtro por categoría y buscador instantáneo en tiempo real.
- [`src/routes/qr.html`](./src/routes/qr.html) — Tarjeta digital de contacto rápido con código QR vectorial escaneable.
- [`docs/portfolio-improvement/`](./docs/portfolio-improvement/) — Documentación completa del proceso de investigación, auditoría, estrategia de contenido, arquitectura UX, dirección de arte, curaduría de activos, especificación de movimiento, SEO/rendimiento y aseguramiento de calidad (QA).

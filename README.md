## 👨‍💻 Sobre mí

Soy desarrollador Front-End & Full Stack y Técnico Superior Universitario en Informática, con más de 6 años de experiencia previa en soporte técnico de sistemas, administración de redes (PRTG), Cloud Computing (Azure/Linux) y gestión logística ERP.

Cuento con triple certificación oficial del SEPE (Gobierno de España) en Desarrollo Web Cliente/Servidor, Cloud Computing y Ciberseguridad Empresarial, además del diploma Full Stack Software Developer (360 horas) por 4Geeks Academy y especialización en React por Academia Desafío Latam.

* 💻 Desarrollo interfaces modernas con React 18, Vite, JavaScript (ES6+), TypeScript, HTML5 y CSS3/Tailwind.
* ⚡ Coreografía de microinteracciones y animaciones de alto rendimiento con GSAP 3 y ScrollTrigger.
* 🔌 Diseño, desarrollo y consumo de APIs RESTful con Node.js, Express, Python y Flask.
* 🗄️ Modelado y gestión de datos con MongoDB, Mongoose, PostgreSQL y SQLAlchemy.
* 🔐 Implementación de autenticación segura con JWT, Bcrypt y Firebase.
* 🧪 Testing unitario y de integración con Jest y Vitest.
* 🏭 Experiencia en entornos industriales automatizados (PLC Siemens) y control de procesos.

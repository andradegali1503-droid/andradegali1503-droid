## 🌟 Proyecto destacado

### 🍽️ MesaClick

MesaClick es una aplicación Full Stack diseñada para digitalizar la gestión de reservas de un restaurante.

La plataforma permite a los usuarios registrarse, iniciar sesión, consultar el menú, reservar mesas y gestionar sus reservas. También incorpora funcionalidades privadas para la administración del restaurante.

### Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Autenticación mediante JWT.
* Roles diferenciados para clientes y administradores.
* Creación, modificación y cancelación de reservas.
* Control de disponibilidad y validación de horarios.
* Gestión del menú y las reseñas.
* Integración con una API meteorológica.
* Confirmaciones mediante correo electrónico.
* Rutas protegidas y validación de datos.
* Pruebas automatizadas de frontend y backend.
